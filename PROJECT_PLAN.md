# Project charter

**Audience:** aspiring laptop buyer or retail category analyst.

**Problem:** difficult to compare prices across laptops with different specifications.

**Goal:** show credible within-sample benchmarks, generate transparent estimates, flag comparisons for review.

**KPIs:** sample size, median price, category price distribution, benchmark percentage gap, MAE/RMSE/R².

**Acceptance criteria:** pipeline runs from raw CSV; duplicate correction reproducible; tests pass; CV baseline included; holdout reported; UI interactive; limitations disclosed.

**Out of scope:** real-time market prices, actual shop availability, recommendations based on quality, definitive valuation.
